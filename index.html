Available API Endpoints

  • POST /api/auth/register - Register new user
  • POST /api/auth/login - Login
  • GET /api/auth/session - Get session (requires auth)
  • POST /api/qr/generate - Create QR code (requires auth)
  • GET /api/qr/my-qrs - List your QR codes (requires auth)
  • GET /api/profile - Get profile (requires auth)
  • GET /api/history - Get history (requires auth)
